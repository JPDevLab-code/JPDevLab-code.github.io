Instalación de Dependencias

Configura todas las herramientas necesarias para que UltraPDF funcione al 100%. Sigue el video o usa los pasos de abajo para copiar y pegar cada comando.

1

Chocolatey + Python + PATH

Chocolatey es el gestor de paquetes para Windows. Piensa en él como apt en Linux o brew en macOS. Sin él, tendrías que buscar, descargar e instalar cada herramienta manualmente. Chocolatey automatiza todo desde la terminal.

Python 3 es necesario para herramientas como OCRmyPDF, WeasyPrint y OpenCV que UltraPDF usa internamente para OCR avanzado, conversiones HTML→PDF y procesamiento de imágenes.

Abre PowerShell como Administrador y pega este bloque completo:

# 1. Instalar Chocolatey Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1')) # 2. Instalar Python 3 choco install python3 -y # 3. Configurar PATH de usuario para Python $pythonDir = "$env:LOCALAPPDATA\Programs\Python\Python312" $pythonScripts = "$env:LOCALAPPDATA\Programs\Python\Python312\Scripts" $currentPath = [Environment]::GetEnvironmentVariable("PATH", "User") if ($currentPath -notlike "*$pythonDir*") { [Environment]::SetEnvironmentVariable("PATH", "$currentPath;$pythonDir;$pythonScripts", "User") $env:PATH += ";$pythonDir;$pythonScripts" } Write-Host "Paso 1 completado" -ForegroundColor Green

Tip: Si ya tienes Chocolatey o Python instalados, puedes saltar esos sub-pasos. Asegúrate de que Python esté en el PATH.

2

Herramientas del Sistema

Instala todas las herramientas nativas de una sola vez con Chocolatey. Cada una agrega funcionalidades específicas a UltraPDF:

  • Ghostscript — Reparación, compresión avanzada, recorte y PDF/A
  • qpdf — Reparación y compresión rápida
  • Tesseract OCR — Reconocimiento óptico de caracteres
  • LibreOffice — Conversión de Word, Excel, PowerPoint a PDF
  • ImageMagick — Optimización de imágenes line-art
  • Poppler — Conversión de PDF a HTML/Markdown
  • Calibre — Conversión de PDF a EPUB
  • WinRAR — Empaquetado en formato CBR
# Instalación masiva con Chocolatey choco install ghostscript qpdf tesseract libreoffice-fresh imagemagick poppler calibre winrar -y Write-Host "Paso 2 completado" -ForegroundColor Green
3

Paquetes Python (pip)

Estas librerías de Python extienden las capacidades de UltraPDF. Requieren que Python y Ghostscript ya estén instalados (Pasos 1 y 2).

  • OCRmyPDF — OCR avanzado en archivos PDF existentes
  • WeasyPrint — Conversión de HTML, URL y Markdown a PDF
  • OpenCV — Separación y extracción de fotos en documentos escaneados
# Actualizar pip e instalar librerías de Python python -m pip install --upgrade pip python -m pip install ocrmypdf weasyprint opencv-python Write-Host "Paso 3 completado" -ForegroundColor Green
4

Verificar en UltraPDF

Una vez instaladas todas las dependencias:

  • Cierra la ventana de PowerShell
  • Abre la aplicación UltraPDF
  • Ve a Ajustes → Dependencias del Sistema
  • Pulsa "Comprobar de nuevo"
  • Las 13 dependencias aparecerán marcadas como Installed

¿Alguna dependencia no aparece? Asegúrate de que la herramienta esté en el PATH del sistema. En PowerShell puedes verificar con: where.exe ghostscript o tesseract --version.
